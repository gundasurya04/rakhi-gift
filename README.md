# Rakhi Festival Gift Website

A beautiful, emotional, and interactive single-page website that a brother can personalize and send to his sister as a digital Rakhi gift.

## Features
- **Personalized Greeting**: Enter Brother and Sister names to customize the entire experience.
- **Interactive Rakhi Tying**: A virtual Rakhi that the sister can "accept".
- **Heartfelt Message**: A typewriter effect letter from brother to sister.
- **Virtual Gift Unboxing**: A clickable gift box that reveals a surprise.
- **Memory Lane**: Cards to display favorite childhood/recent memories.
- **Rakhi Promises**: Animated promises of protection and love.
- **Send Love**: An interactive heart button that floats hearts on screen.
- **Premium Animations**: Built with GSAP and Canvas Confetti for stunning visual effects.

## How to Customize
1. **Memories**: 
   - Add your own photos to the `assets/memories/` folder.
   - Update the image `src` paths in the `index.html` file (under the `#memories-section`) to point to your new images.
2. **Music**: 
   - Replace the audio `src` link in `index.html` with your favorite Rakhi song or a local `.mp3` file (e.g., `assets/music.mp3`).
3. **Gift**: 
   - Change the text "A Virtual Jewelry Box!" in `index.html` to whatever gift you plan to give her.

## How to Run
Simply open `index.html` in any modern web browser (Chrome, Safari, Firefox). No backend server is required!
